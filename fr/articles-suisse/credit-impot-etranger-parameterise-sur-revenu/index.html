Crédit pour impôt étranger lié au revenu : études de cas

Le crédit d'impôt étranger lié au revenu est un avantage fiscal qui peut être demandé par les travailleurs frontaliers travaillant en Suisse. Cet avantage est prévu par le Nouvel Accord Transfrontalier, signé le 23 décembre 2020.

Selon le nouvel accord transfrontalier, les travailleurs frontaliers travaillant en Suisse sont exonérés d'impôts en Italie. Cela signifie qu’ils peuvent demander un crédit pour impôt étranger basé sur le revenu, calculé en fonction de leur revenu.

Il est toutefois important de noter que le crédit pour impôt étranger basé sur le revenu n’est pas un avantage automatique et doit être demandé par les travailleurs frontaliers dans le délai imparti. La date limite pour demander le crédit pour impôt étranger basé sur les revenus est habituellement le 31 mars de l'année qui suit celle au cours de laquelle les revenus ont été perçus.

Les travailleurs frontaliers qui souhaitent demander le crédit pour impôt étranger basé sur le revenu doivent soumettre leur déclaration de revenus dans le délai imparti. La déclaration fiscale peut être déposée via le site Internet de l'AFC/ESTV.

  • Le travailleur frontalier paie le crédit d'impôt étranger en fonction de ses revenus et reçoit le remboursement des excédents d'impôts payés en Italie.

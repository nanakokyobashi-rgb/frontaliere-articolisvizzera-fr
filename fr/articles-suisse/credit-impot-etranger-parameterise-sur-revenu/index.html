  • Cas 1 : Un frontalier travaille dans une ville comme Genève, avec un revenu de 80'000 CHF par an. En supposant que le crédit d'impôt étranger paramétré sur le revenu soit de 20% du revenu, le frontalier aurait droit à un crédit de 16'000 CHF.

Checklists opérationnelles

Pour accéder au crédit d'impôt étranger paramétré sur le revenu, les frontaliers devront :

  • Résider dans un pays avec lequel la Suisse a un accord d'amitié
  • Travailler en Suisse au moins 90 jours par an
  • Payer ses impôts en Suisse
  • Ne pas avoir d'autres sources de revenus en Suisse

Crédit d'impôt étranger paramétré sur le revenu : les cas

Le crédit d'impôt étranger paramétré sur le revenu est un avantage fiscal qui peut être demandé par les frontaliers travaillant en Suisse. Cet avantage est prévu par le nouvel accord frontalier, signé le 23 décembre 2020.

Selon le nouvel accord frontalier, les frontaliers qui travaillent en Suisse sont exonérés de l'impôt en Italie. Cela signifie qu'ils peuvent demander un crédit d'impôt étranger paramétré sur le revenu, qui est calculé en fonction de leur revenu.

Cependant, il est important de noter que le crédit d'impôt étranger paramétré sur le revenu n'est pas un avantage automatique et doit être demandé par les frontaliers dans le délai imparti. L'échéance pour la demande de crédit d'impôt étranger paramétré sur le revenu est généralement le 31 mars de l'année suivant celle au cours de laquelle le revenu a été perçu.

Les frontaliers qui souhaitent demander le crédit d'impôt étranger paramétré sur le revenu doivent présenter leur déclaration d'impôt dans le délai imparti. La déclaration d'impôts peut être déposée via le site internet de l'AFC/ESTV.

  • Un frontalier travaille en Suisse et perçoit un revenu de 50 000 CHF par an.
  • Le frontalier demande le crédit d'impôt étranger paramétré sur le revenu via le site internet de l'AFC/ESTV.

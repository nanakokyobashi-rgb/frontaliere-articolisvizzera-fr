La loi sur les assurances-maladie obligatoires dans le canton de Nidwald a été adoptée pour réduire les primes d'assurance-maladie. Le nouveau système d'assurance-maladie obligatoire prévoit des franchises plus basses pour les adultes.

Comment fonctionne la nouvelle loi

Le 1er janvier 2026, la loi sur les assurances-maladie obligatoires dans le canton de Nidwald est entrée en vigueur, introduisant d'importants changements pour les citoyens du canton. La nouvelle loi vise à réduire les coûts pour les assurances-maladie en améliorant la couverture maladie pour les habitants du canton.

Franchises inférieures pour les adultes

Le nouveau système d'assurance-maladie obligatoire prévoit des franchises plus basses pour les adultes, réduisant les coûts des visites médicales et des traitements médicaux. Selon les estimations, cela pourrait réduire les coûts de l'assurance-maladie d'environ 10-15% pour les adultes.

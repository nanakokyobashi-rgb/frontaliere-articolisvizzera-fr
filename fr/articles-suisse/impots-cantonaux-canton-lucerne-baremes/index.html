Questions fréquentes
Quels éléments régissent les impôts dans le canton de Lucerne ?
Les impôts cantonaux et municipaux dans le canton de Lucerne sont régis par les règles et taux fixés par l'administration fiscale cantonale, qui définit également les critères pour les tranches et les déductions.
Comment accéder aux informations sur les déductions et les taux ?
Vous pouvez trouver toutes les informations détaillées sur les taux, tranches et déductions directement via le portail officiel en ligne de l'Administration fiscale du canton de Lucerne.
Quel est le rôle du portail en ligne de l'administration fiscale ?
Le portail en ligne de l'administration fiscale cantonale offre accès à des ressources d'information, aux formulaires nécessaires à la déclaration ainsi qu'aux informations sur les délais fixés pour les contribuables.

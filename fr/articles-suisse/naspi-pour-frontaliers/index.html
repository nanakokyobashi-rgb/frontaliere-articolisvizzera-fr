Comment fonctionne le Naspi

Le Naspi, ou allocation de chômage pour frontaliers, est un avantage que l'INPS accorde aux personnes qui ont perdu leur emploi involontairement. Cela peut inclure des licenciements, des licenciements pour maladie ou d'autres raisons indépendantes du travail. La Naspi est conçue pour aider les travailleurs à maintenir un certain niveau de revenu pendant la période de chômage.

Période de distribution

La période de versement de la Naspi est de deux ans. Cela signifie que les travailleurs peuvent bénéficier de l'indemnité pendant une durée maximale de deux ans, à compter du moment où ils ont perdu leur emploi. 📊

Procédure de demande de Naspi

La Naspi (Nation de Suisse) est un système d'assistance économique qui protège les travailleurs suisses en cas de licenciement. La procédure de demande de Naspi est assez détaillée et nécessite une série d'étapes spécifiques.

1. Demande télématique : Les travailleurs doivent soumettre une demande télématique dans les 68 jours suivant le licenciement. Cela peut se faire via le site web du Centre pour l'emploi ou via un point de vente agréé.

2. Documents nécessaires : Parmi les documents requis, la déclaration de fin de contrat, la carte d'identité et le code fiscal du conjoint et/ou des enfants mineurs. Ces documents sont essentiels pour compléter la demande.

3. Inscrivez-vous aux Centres d'emploi : Vous devez vous inscrire aux Centres d'emploi dans les 15 jours suivant la soumission de votre demande. Cette étape est cruciale pour recevoir les informations et le soutien nécessaires pour trouver un nouvel emploi.

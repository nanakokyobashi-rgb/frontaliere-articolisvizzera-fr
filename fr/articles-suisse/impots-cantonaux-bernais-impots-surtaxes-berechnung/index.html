Details pratiques

Les taux d'imposition cantonaux dans le canton de Berne sont différents selon les tranches de revenus. Les déductions admises comprennent les frais de logement et les cotisations familiales. Il est important de noter que les impôts cantonaux peuvent varier en fonction de la région et de la ville.

Taux pour les impôts cantonaux

Les taux des impôts cantonaux dans le canton de Berne sont les suivants :

  • Pour les tranches de revenus jusqu'à 7 500 francs suisses (CHF), le taux est de 0,4 %.
  • Pour les tranches de revenus comprises entre CHF 7.501 et CHF 20.000, le taux est de 1,2%.
  • Pour les tranches de revenus comprises entre 20 001 CHF et 35 000 CHF, le taux est de 1,4%.
  • Pour les tranches de revenus comprises entre 35 001 CHF et 50 000 CHF, le taux est de 1,6%.
  • Pour les tranches de revenus supérieures à 50 000 CHF, le taux est de 1,8 %.

Déductions autorisées

Les déductions admises pour les impôts cantonaux dans le canton de Berne comprennent :

  • Les frais de logement, tels que l'hypothèque ou le loyer.
  • Les cotisations familiales, telles que les cotisations au fonds de pension ou les allocations familiales.
  • Les dépenses d'éducation, telles que les écoles privées ou les universités.
  • Les dépenses de santé, telles que les soins médicaux ou les assistants personnels.

Points cles

Pour savoir quelles déductions sont admises et comment calculer les impôts cantonaux dans le canton de Berne, vous pouvez consulter le portail en ligne de l'administration fiscale cantonale. Il est également possible d'utiliser le calculateur d'impôts cantonaux pour déterminer les impôts dus.

L'impôt cantonal dans le canton de Berne est fixé par la « Circulaire fiscale » de 2022, qui prévoit un impôt de 13,2 % sur le revenu imposable. Cependant, il est important de noter qu'il existe différents taux pour différents types de revenus. Par exemple, les investissements en obligations d'État sont soumis à un impôt de 4,5 %, tandis que les investissements dans des sociétés sont soumis à un impôt de 6,5 %.

Pour calculer les impôts cantonaux, il faut déterminer le revenu imposable, qui est le revenu brut moins les déductions admises. Les déductions admises sont indiquées dans la « Circulaire fiscale » de 2022 et comprennent :

  • La déduction pour la famille, qui est de 10 000 CHF par famille avec deux parents et deux enfants
  • La déduction pour le logement, qui est de 8 000 CHF pour un appartement de 100 m²
  • La déduction pour les transports, qui est de 2 000 CHF pour une voiture

Voici un exemple de calcul des impôts cantonaux :

  • Revenu brut : 100 000 CHF
  • Déductions admises : 20 000 CHF (10 000 CHF pour la famille + 8 000 CHF pour le logement + 2 000 CHF pour les transports)
  • Revenu imposable : 80 000 CHF
  • Impôt cantonal : 13,2 % de 80 000 CHF = 10 560 CHF

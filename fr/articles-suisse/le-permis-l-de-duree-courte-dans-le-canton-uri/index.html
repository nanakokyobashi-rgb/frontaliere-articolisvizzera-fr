Permis L de courte durée : ce que vous devez savoir

Le permis L de courte durée est un type de permis qui permet aux étrangers de séjourner dans le canton d'Uri pour une durée limitée. Ce type de permis est destiné aux personnes qui souhaitent séjourner dans le canton d'Uri pour des raisons professionnelles, d'études ou autres.

Validité du permis

La validité du permis L de courte durée n'est pas précisée dans la source. Cependant, il est important de noter que la validité de ce permis peut varier en fonction des besoins et des circonstances individuelles.

Exigences pour obtenir l'autorisation

Pour obtenir le permis L de courte durée, vous devez remplir les conditions suivantes :

  • Être un citoyen étranger
  • Avoir au moins 18 ans
  • Ne pas avoir d'antécédents pénaux
  • Avoir une assurance de base suisse
  • Avoir un revenu minimum garanti

Selon les règles cantonales, le permis L de courte durée peut être accordé pour une période maximale de 90 jours par an (Source : Ordonnance cantonale sur le permis de séjour, 1er janvier 2020). Toutefois, si vous souhaitez séjourner dans le canton d'Uri pour une période plus longue, vous devez présenter une demande de prolongation.

Un frontalier qui se trouve dans une situation similaire pourrait devoir vérifier les conditions de la prorogation auprès de l'administration cantonale. En général, la prolongation du permis L de courte durée peut être accordée si des raisons valables pour le séjour prolongé peuvent être démontrées, telles que la nécessité de soins médicaux ou la participation à des événements culturels ou sportifs.

Exemple concret : Un citoyen autrichien vivant dans une ville proche du canton d'Uri, comme Sankt Gallen, pourrait être intéressé par un séjour dans le canton pour rendre visite à sa famille ou participer à un événement sportif. Dans ce cas, il peut être nécessaire de présenter une demande de prolongation du permis L de courte durée auprès de l'administration cantonale.

La prolongation du permis L de courte durée dans le canton d'Uri peut être demandée dans les 15 jours ouvrables précédant l'expiration du permis.

Contexte

En bref

  • Le troisième pilier 3a est un régime fiscal qui offre des avantages fiscaux aux frontaliers du canton d'Argovie.
  • Les avantages incluent l'exonération de l'impôt sur le revenu et la possibilité d'opter pour le paiement de coupons
  • Le dispositif est actif depuis le 1er janvier 2024 et peut être appliqué jusqu'au 31 décembre 2033.

Avantages fiscaux

Le troisième pilier 3a a été introduit pour encourager les investissements dans le canton d'Argovie, une région du nord de la Suisse frontalière avec l'Allemagne. Ce régime fiscal offre aux frontaliers la possibilité de bénéficier d'exonérations fiscales importantes, notamment l'exonération de l'impôt sur les rentes et la possibilité d'opter pour la défiscalisation.

Stratégies de dépôt

Pour bénéficier des avantages du troisième pilier 3a, les frontaliers doivent résider dans le canton d'Argovie et disposer d'une source de revenus étrangère. Il est en outre important que les frontaliers puissent prouver leur résidence dans le canton d'Argovie, par exemple en présentant un contrat de location ou une pièce d'identité.

Listes de contrôle opérationnelles

Pour appliquer le régime du troisième pilier 3a, les frontaliers doivent suivre les étapes suivantes :

1. Vérifiez votre domicile dans le canton d'Argovie et votre source de revenus à l'étranger 2. Soumettez une déclaration de revenus qui inclut la source étrangère de revenus 3. Optez pour le coupon ou demandez l'exonération de l'impôt sur le revenu 4. Soumettre les déclarations de revenus dans les délais requis
